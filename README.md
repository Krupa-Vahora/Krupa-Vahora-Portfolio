# Krupa Vahora - Portfolio Website

A modern, high-performance portfolio website for **Krupa Vahora**, Senior React Native & Full Stack Developer. Built with React, TypeScript, Tailwind CSS, and Vite.

## 🛠️ Tech Stack
- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Tooling**: Oxlint

## 📂 Project Architecture
```text
src/
├── types/              # TypeScript interfaces (PersonalInfo, Projects, Skills, etc.)
├── constants/          # Configuration and portfolio data
├── utils/              # Utility functions (contact delivery, clipboard)
├── components/
│   ├── icons/          # Custom SVG icons
│   ├── Header.tsx      # Sticky navbar & theme switcher
│   ├── Hero.tsx        # Introduction, social links & key metrics
│   ├── Projects.tsx    # Enterprise project showcases & store links
│   ├── Skills.tsx      # Core technical proficiencies
│   ├── Experience.tsx  # Work timeline & education
│   ├── Contact.tsx     # Full-width contact form
│   └── Footer.tsx      # Footer & copyright
└── App.tsx             # Root layout orchestrating dark/light mode
```

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/krupa-vahora/<repository-name>.git
   cd <repository-name>
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
